## 🎯 Installation Flow

```

        ↓

│ check_prerequisites │ → Verify curl, test GitHub connectivity
└─────────────────────┘
        ↓
┌─────────────────────┐
│ backup_existing     │ → Create ~/.copilot.backup-TIMESTAMP/
└─────────────────────┘
        ↓
┌─────────────────────┐
│ collect_user_input  │ → Prompt for Java version, package, etc.
└─────────────────────┘
        ↓
┌─────────────────────┐
│ install_agents      │ → Download + process templates
│ install_skills      │

│ install_patterns    │
│ install_usage_guide │
└─────────────────────┘
        ↓
┌─────────────────────┐

└─────────────────────┘
        ↓
┌─────────────────────┐
│ display_summary     │ → Show results, backup location, next steps
└─────────────────────┘
```

## 🔧 Template Variable Substitution

The installer replaces the following placeholders:

| Placeholder               | Example Value                   | Source                    |
|---------------------------|---------------------------------|---------------------------|
| `{{COPILOT_HOME}}`        | `~/.copilot`                    | Hardcoded                 |
| `{{LANG_VERSION}}`        | `17`                            | User input / default      |
| `{{BUILD_TOOL}}`          | `Maven`                         | User input / default      |
| `{{SPRING_BOOT_VERSION}}` | `3.5.11`                        | User input / default      |
| `{{BASE_PACKAGE}}`        | `com.example.app`               | User input / default      |
| `{{TEST_PATH}}`           | `src/test/java/com/example/app` | Derived from BASE_PACKAGE |
| `{{MAIN_PATH}}`           | `src/main/java/com/example/app` | Derived from BASE_PACKAGE |

## 🛡️ Safety Features

1. ✅ **Automatic Backup**: Creates timestamped backup before any changes
2. ✅ **Idempotent**: Can run multiple times safely
3. ✅ **Network Validation**: Tests GitHub connectivity before download
4. ✅ **Permission Checks**: Validates write access upfront
5. ✅ **Graceful Failures**: Clear error messages with actionable solutions
6. ✅ **Set -e -u**: Fails fast on errors or undefined variables
